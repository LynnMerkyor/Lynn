## 客户端候选

- 未配置搜索账户：包括使用模型 BYOK 的用户，默认调用 Lynn 云端搜索。
- 设置 → 模型服务 → 其他模型 → 搜索引擎：选择 DeepSeek Search (BYOK)，填写自己的搜索 API Key 并验证保存，改由自有账户优先执行搜索。失败回退云端；选择云端默认可以切回。
- CLI 共用搜索执行代码，search.provider=deepseek、search.api_key 配置行为一致。不将搜索密钥当作聊天模型密钥。
- Search 只执行模型查询，保持完整地点、时间、site: 等运算符；超过 128 Unicode 字符明确反馈，不截断查询。
- 保留摘要、来源 URL、发布时间、检索时间及供应商返回的排序指标。指标不是事实正确性保证。
- 默认 need_content=false；只有模型需要进一步证据时才调用既有 web_fetch。本次不替换 Fetch 后端。

## 复查修复

1. 旧云端通用查询先经过关键词扩写与固定事实捷径：DeepSeek 首选路径绕开这些规则，失败时保留旧源以维持可用性，未宣称已移除整个仓库的全部历史启发式。
2. 搜索 BYOK 曾排在公共 Brain 后：现在显式搜索配置优先，模型 BYOK 与搜索 BYOK 互不推断。
3. 配置读取曾逐字段混合运行时设置与旧配置：改为整组读取，防止新 provider 搭配旧 provider 密钥。
4. 切换搜索 provider 时旧密钥可能残留：界面清空旧密钥与地址，延迟设置回读也不能重新填回旧密钥。
5. 来源日期在客户端映射中被丢弃：现在保留并提供给模型。
6. 共享 HTTP 适配器覆盖请求及响应体的 10 秒期限，失败正文不写入错误或日志；每进程同密钥请求间隔至少 250ms，排队过长快速回退，不自动重试 401/402/429。
7. 云端主源与旧备用链串行累计可能超出旧客户端 14 秒等待窗口：云端 DeepSeek 首选最多 5 秒，备用源并行最多 7 秒，整个检索预算约 12 秒；DeepSeek 路径的备用查询也保持原样，不重新套用领域关键词扩写。客户端的超时现在覆盖响应正文，不在收到响应头时提前解除。
8. 工具取消没有传入搜索执行链：现在贯通主动取消，取消后立即终止，不再启动备用源；包括已经取消、请求途中取消的回归测试。
   Brain 路由、工具分发和搜索 HTTP 连接断开也传播取消；搜索中止不再被转换为普通成功工具文本，停止后不启动后续搜索。
9. HTML 备用源无期限：请求和响应正文共用单源期限，客户端完整搜索链限制为 30 秒，包含付费源、Brain 与 HTML 回退。
10. 设置验证旧响应可能覆盖新的选择：新界面先执行不保存的验证，只有仍对应当前输入的结果才提交；切换选项或编辑输入会使旧验证失效，提交阶段阻止并发更改。
11. DeepSeek 汇总摘要与条目重复：模型可见文本只保留完整条目、日期和 URL；结构化来源仍保留，非抽取式独立总结不删除。

## 边界与后续门禁

- 线上当前为单个 Brain v2 进程；多实例时必须升级为跨进程账号级限流，不能把本地节流当作全账号配额管理。
- 通用网页搜索不是专用天气、行情或比分源；天气测试出现过摘要与抓取正文不一致，模型必须核对日期、地点与不同来源，不可只依据 HTTP 200 或排序分数回答。
- 老客户端的查询扩写仍可能存在；本次云端切换即可受益，但消除客户端扩写、增加搜索 BYOK 选项和新提示需要 V0.87.3。
- 本次架构复查聚焦搜索传输、路由、配置与凭据边界，不等同于证明全仓无缺陷。
- 测试和部署证据在 output/deepseek-search-eval/，包含原失败记录、修复后回归、文件摘要、公网签名调用和默认模型真实工具调用。发布需另行确认。
