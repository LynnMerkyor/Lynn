Lynn CLI / Lynn Code

给开发者和其他智能体的安装方式

Lynn CLI 当前最新为 v0.86.3。它是 Lynn 的终端版:跑在命令行里的 AI 编码助手,带终端 TUI、Markdown 渲染、流式输出、工具调用和长任务续跑。 一行命令装好,不用克隆仓库、不用编译;也可以被 Claude Code、Codex CLI、Kimi Code、Qwen CLI、CI 或 Lynn GUI Fleet 以无交互方式调用。

Node.js 20 LTS 或 22 LTS

1. 先准备 Node 环境

如果机器已经有 Node 20+ 和 npm，可以直接跳到下一步。先用 node -v 确认版本不低于 v20。

node -v

# macOS(Homebrew)
brew install node@20

# macOS / Linux(nvm)
nvm install 20 && nvm use 20

# Windows
winget install OpenJS.NodeJS.LTS
首次安装 / 覆盖升级

2. 安装 Lynn CLI

第一次安装和覆盖旧版本都用这条命令。--force 首次安装也无害,并能覆盖旧的 lynn/Lynn 命令软链接,避免 npm 提示 EEXIST。包走腾讯云镜像,国内直连快。

npm install -g --force https://download.merkyorlynn.com/downloads/cli/lynn-cli-0.86.3.tgz
启动命令

3. 启动 Lynn

默认走 Brain V2 路由:本地 Lynn Brain 可用时优先本地,不可用时自动回到远端 Brain。编码任务默认使用 auto harness:协议与当前认证/provider/model 的真实预检通过才进入 Codex app-server,否则在启动前使用 Lynn 原 Loop；ask/workspace-write 保留审批，多模态、JSON 逐工具审计、Ultra 和 never deny-all 继续走原架构。实验性 manager 仍可通过 Lynn manager run -p ... --jsonl 显式调用。

Lynn                 # 交互式聊天 TUI
Lynn code            # 编码 agent TUI
Lynn manager run -p "拆分并验收这个长任务" --jsonl
Lynn --version       # 应输出 0.86.3
Lynn agents          # 输出可复制的 Fleet / 其他 CLI 调用方式

# 无交互编码 worker 示例
Lynn code -p "fix tests, run the suite, summarize the diff" \
  --json \
  --cwd /path/to/worktree \
  --approval yolo \
  --sandbox danger-full-access \
  --save-session

安装前你可能想知道

我怎么知道我的 Mac 是 Apple Silicon 还是 Intel？

点击左上角苹果菜单，选择“关于本机”。如果看到 M 系列芯片，就是 Apple Silicon；如果看到 Intel，就是 Intel 版。

Windows 弹出安全提示还能装吗？

可以。正式发布安装包会完成 Windows 代码签名；SmartScreen 仍可能因为新版应用声誉积累不足而提示确认。

我想看更新说明或校验原始发布记录怎么办？

你可以直接打开 Gitee Release 页面查看所有历史版本、更新说明和备用下载入口。

V0.86.3:Agent Loop 稳定性与确定性回退

V0.86.3 加固 Lynn Code/CLI 默认 auto 的 Codex app-server harness，并保持原 Loop 作为兼容与安全回退。可选状态接口不可用时仍会继续做带认证的 Responses 真实预检；显式 Codex 模式也必须验证当前 provider/model。GUI 与 CLI 同步修复空答、单轮接班和来源追踪。 Windows 安装包继续内置 llama.cpp 运行时，最终 NSIS payload 仍会在 Windows 上完成真实 GGUF 加载和连续生成门禁。

  • 启动前探测 app-server 可执行文件、协议、认证与当前 provider/model
  • 兼容才走 Codex harness；失败或不支持时直接选择原 Loop
  • 本地模型失败只做单轮 Brain 接班，不永久修改会话模型
  • 空正文或 reasoning-only 候选立即交接，并进入短暂跨轮 cooldown
  • Ink TUI 不再把空 assistant 或 unmatched user 写进后续上下文
  • GUI turn_end 透传 streamSource，便于定位本地或 Brain fallback
  • 多模态、JSON 审计、Ultra 和严格审批保持原有经过验证的执行语义
  • CLI 记录 requested/selected harness、协议与选择原因；GUI/CLI 共享终态契约
  • Windows 内置 llama-server.exe、依赖 DLL、许可证和逐文件 SHA-256 清单
  • Windows 最终安装器门禁真实加载固定 GGUF 并连续生成两次
  • 生产 Brain 必须公开 responses 与 appServerHarness 运行态能力
  • macOS/Windows 打包统一经过 Agent regression、CLI100、GUI100、全部 UI 与真实安装门禁
